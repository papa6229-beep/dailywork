# 바나나몰2 AI 운영 시스템 — 보고 화면

버셀에 올려서 쓰는 개발 현황 보고서입니다.

- **`https://주소/`** → 보고 화면 (읽기 전용). 이 주소를 회장님께 드리면 됩니다.
- **`https://주소/?edit=1`** → 입력 화면. 비밀번호를 넣어야 저장됩니다.

---

## 배포 순서

### 1. 깃허브에 올리기

이 폴더를 통째로 깃허브 새 저장소에 올립니다.

```
banamall2/
├─ index.html
├─ package.json
└─ api/
   └─ data.js
```

### 2. 버셀에 연결

1. vercel.com → **Add New… → Project**
2. 방금 만든 깃허브 저장소 선택
3. Framework Preset은 **Other** 그대로 두고 **Deploy**

### 3. 저장소(Redis) 붙이기

데이터를 담을 곳입니다. 이걸 안 하면 저장이 안 됩니다.

1. 버셀 프로젝트 → **Storage** 탭 → **Create Database**
2. Marketplace에서 **Upstash → Redis** 선택
3. 무료 플랜으로 생성 후, 이 프로젝트에 **Connect**

연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 두 개가 자동으로 들어갑니다. 직접 만질 필요 없습니다.

### 4. 입력 비밀번호 정하기

1. 버셀 프로젝트 → **Settings → Environment Variables**
2. 이름 `EDIT_KEY`, 값은 원하는 비밀번호 (예: `banana2026!`)
3. 저장 후 **Deployments 탭에서 Redeploy** (환경변수는 재배포해야 반영됩니다)

### 5. 확인

- `https://주소/?edit=1` 접속 → 비밀번호 입력 → 아무 칸에나 입력
- `https://주소/` 접속 → 입력한 내용이 읽기 전용으로 보이면 완료

---

## 알아둘 점

**`?edit=1`은 화면을 감추는 것이지 보안이 아닙니다.**
회장님이 주소 뒤에 `?edit=1`을 붙이면 입력 화면이 열립니다. 다만 `EDIT_KEY`를 모르면 **저장은 안 됩니다.** 실제 데이터는 안전합니다.

**저장 방식**
입력을 멈추고 1.5초 뒤 자동 저장됩니다. 우측 상단에 "저장됨 14:23"이 뜨면 서버에 들어간 겁니다. 급할 때는 `지금 저장` 버튼을 누르세요.

**버셀 요금**
무료(Hobby) 플랜은 개인·비영리 프로젝트용이라, 회사 업무용으로 계속 쓰려면 Pro($20/월) 대상입니다. 내부에서 몇 명만 보는 정도면 실사용량은 무료 한도에 한참 못 미치지만, 약관상 그렇다는 점은 알고 계시는 게 좋습니다.
